# BLUE NOTE

회의를 녹음하면 글로 받아쓰고, 누가 말했는지 나누고, 회의록을 써서 Word 파일로 내려 주는 프로그램입니다.
모든 처리는 내 PC 안에서 합니다. 녹음과 회의 내용은 인터넷으로 나가지 않습니다.

## 쓸 수 있는 PC

| | 조건 |
| --- | --- |
| Mac | Apple Silicon(M1 이상), macOS 14 Sonoma 이상 |
| Windows | Windows 10 또는 11, 64비트(Intel, AMD CPU) |
| 메모리 | 8GB 이상, 16GB 이상 권장 |
| 디스크 | 여유 공간 15GB 이상 (AI 모델을 받습니다) |

Intel Mac과 ARM Windows는 쓸 수 없습니다. 음성 인식 라이브러리가 지원하지 않습니다.

## 설치 (명령 한 줄)

파이썬을 따로 깔 필요가 없습니다. 아래 명령 하나가 필요한 것을 모두 받습니다. 처음에는 5~10분쯤 걸립니다.

### Mac

`Command + Space`를 누르고 `터미널`을 입력해 엽니다. 아래 줄을 붙여 넣고 Enter를 누릅니다.

```sh
curl -fsSL https://raw.githubusercontent.com/holyshine11/meeting-doc/main/install.sh | sh
```

### Windows

시작 메뉴에서 `PowerShell`을 엽니다(관리자로 열 필요 없음). 아래 줄을 붙여 넣고 Enter를 누릅니다.

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/holyshine11/meeting-doc/main/install.ps1 | iex"
```

설치가 끝나면 화면 마지막에 실행 방법이 나옵니다. 설치 위치는 아래와 같습니다.

- Mac : `~/meeting-doc`
- Windows : `C:\Users\사용자이름\meeting-doc`. 사용자 이름에 한글이나 공백이 있으면 `C:\meeting-doc`에 설치합니다(한글 경로에서 음성 인식 모델을 못 읽는 일을 막으려고).

## 실행

**터미널(PowerShell)을 새로 열고** 아래 두 줄을 입력합니다. 앞으로 쓸 때마다 이렇게 켭니다.

```sh
cd ~/meeting-doc
uv run python app.py
```

Windows에서 `C:\meeting-doc`에 설치됐다면 첫 줄은 `cd C:\meeting-doc`입니다.

브라우저가 자동으로 열립니다. 열리지 않으면 주소창에 `http://127.0.0.1:8765`를 입력하세요.
끌 때는 터미널에서 `Ctrl + C`를 누릅니다. 쓰는 동안에는 터미널 창을 닫지 마세요.

## 처음 한 번만 : 화면 안내 따라 하기

처음 켜면 화면 위에 **처음 쓰기 전에 준비할 것** 상자가 나옵니다. 순서대로 누르면 됩니다.

1. **Ollama 설치하고 켜기** : 회의록을 쓰는 AI 실행기입니다. 설치 명령이 미리 깔아 두었다면 이미 완료로 나옵니다. 아니라면 `Ollama 내려받기`를 눌러 설치하고 Ollama를 실행하세요.
2. **회의록을 쓸 AI 모델 받기** : 메모리 16GB 이상 PC는 권장 모델, 8GB PC는 가벼운 모델을 받습니다. 몇 GB라 시간이 걸립니다.
3. **음성 인식 모델 받기** : 녹음을 글로 받아쓰는 모델입니다. 2단계와 동시에 받아도 됩니다.

셋 다 끝나면 상자가 사라지고 바로 쓸 수 있습니다.

## 쓰는 법

1. **새 회의**를 눌러 녹음합니다. 이미 녹음한 파일이 있으면 **녹음 파일 올리기**를 누릅니다.
2. 녹음을 마치면 받아쓰기와 화자 구분이 자동으로 진행됩니다.
3. 화자 이름을 바꾸고 틀린 문장을 고칩니다. **회의 정보**에서 업체마다 참석자를 적습니다(업체 추가, 삭제 가능. 이름은 쉼표로 나눔).
4. **회의 내용** 탭에서 **회의 내용 요약**을 누르면 오간 이야기를 순서대로 줄여 줍니다. **원본**과 **요약본** 탭을 오가며 견줘 볼 수 있습니다.
5. **회의록 작성**을 누르면 요약, 안건별 논의, 결정 사항, 실행 항목을 정리합니다.
6. Word 파일로 내려받습니다.

녹음, 받아쓴 내용, 회의록은 설치 폴더 안의 `data` 폴더에 회의마다 저장됩니다.

## 업데이트

설치 명령을 다시 실행하면 최신 버전으로 바뀝니다. 회의 기록(`data`), 받아 둔 모델(`models`), 설정(`config.toml`)은 그대로 남습니다.

## 안 될 때

| 증상 | 해결 |
| --- | --- |
| `uv: command not found`, `'uv'은(는) ... 인식되지 않습니다` | 터미널(PowerShell)을 닫고 새로 연 뒤 다시 입력하세요. 설치 직후 열려 있던 창은 uv를 모릅니다. |
| `8765번 포트를 이미 쓰고 있습니다` | 이미 켜져 있습니다. 브라우저에서 `http://127.0.0.1:8765`를 여세요. 다른 프로그램이 쓰는 중이면 `config.toml`의 `port`를 `8766`으로 바꾸세요. |
| 1단계에서 넘어가지 않음 | Ollama가 꺼져 있습니다. Ollama 앱을 실행하세요. Mac은 위쪽 메뉴 막대, Windows는 오른쪽 아래 알림 영역에 라마 아이콘이 보이면 켜진 것입니다. |
| 모델을 받다가 멈추거나 오류 | 인터넷 연결과 디스크 여유 공간을 확인하고 같은 버튼을 다시 누르세요. 받던 곳부터 이어 받습니다. |
| 설치 중 `Apple Silicon(M1 이상) Mac에서만` | Intel Mac은 쓸 수 없습니다. |
| Windows 설치 중 `라이브러리 확인에 실패` | 안내에 나온 주소에서 Microsoft Visual C++ 재배포 가능 패키지를 설치하고 설치 명령을 다시 실행하세요. |
| 녹음 버튼을 눌러도 녹음이 안 됨 | 브라우저 주소창 왼쪽 아이콘을 눌러 마이크를 허용하세요. |
| 녹음은 됐는데 재생하면 소리가 없음, `마이크 소리가 들어오지 않습니다` | 마이크가 막혀 무음이 녹음된 것입니다. Windows는 설정 > 개인 정보(및 보안) > 마이크에서 `데스크톱 앱의 마이크 액세스`를 켜세요. 주소창 왼쪽 사이트 설정에서 쓰는 마이크가 맞는지도 확인하세요. 이미 무음으로 녹음된 회의는 다시 녹음해야 합니다. |
| 받아쓰기가 너무 느림 | `config.toml`의 `[stt]`에서 `model = "small"`로 바꾸고 다시 켜세요. 정확도는 조금 떨어집니다. |
| 회의록이 너무 느리거나 PC가 멈춤 | 2단계에서 가벼운 모델을 받고, 회의록 작성 옆 모델 선택에서 고르세요. |

그래도 안 되면 설치 폴더를 지우고 설치 명령을 다시 실행하세요. 지우기 전에 `data` 폴더를 다른 곳에 복사해 두면 회의 기록을 잃지 않습니다.

## 설정

설치 폴더의 `config.toml`에서 바꿉니다. 바꾼 뒤에는 프로그램을 껐다 켭니다. 항목마다 설명이 적혀 있습니다.

## 보안

- 이 PC에서만 접속할 수 있습니다(`127.0.0.1`). 같은 네트워크의 다른 PC는 들어올 수 없습니다.
- 인터넷은 처음에 프로그램과 AI 모델을 받을 때만 씁니다.
- `data` 폴더에 회의 녹음과 내용이 그대로 들어 있습니다. PC를 다른 사람과 같이 쓴다면 이 폴더 관리에 주의하세요.
